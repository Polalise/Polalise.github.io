# Polalise Portfolio

유병현의 공개용 개발 포트폴리오입니다. 검증 가능한 AI 기능을 웹 서비스로 연결한 경험과 화면, API, 데이터베이스 사이의 계약을 다룬 프로젝트를 소개합니다.

## Local development

```powershell
npm.cmd install
npm.cmd run dev
```

## Validation

```powershell
npm.cmd run check
npm.cmd run test
npm.cmd run build
npm.cmd run test:browser
npm.cmd run test:lighthouse
```

공개 저장소에는 사이트에 노출해도 되는 콘텐츠와 가공된 시각 자산만 포함합니다. 원본 데이터셋, 모델 파일, 개인정보가 포함된 이력서 원본은 포함하지 않습니다.
